# Лабораторная работа 1 — Вариант 14

## Инструкция по запуску
Все программы запускаются через IDLE (клавиша F5) или через терминал командой `python имя_файла.py`. 
Для работы программы `variant.py` не требуются сторонние библиотеки.

## Ответы на теоретические вопросы (для сдачи)
- **Строка vs число:** Строка (str) — это текст в кавычках (например, "17"), число (int) — математическое значение (например, 17). Строки нельзя складывать с числами, поэтому используется функция int().
- **Порядок вычислений:** Сначала выполняются умножение и деление, затем сложение и вычитание. Скобки меняют этот порядок.
- **Временная переменная:** Нужна для обмена значениями двух переменных, чтобы не потерять одно из них (как третья пустая чашка).
- **Форматирование:** Конструкция `:.2f` внутри f-строки выводит ровно два знака после запятой (для денег).
